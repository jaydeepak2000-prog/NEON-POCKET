# NEON POCKET
Animated starfield and perspective-grid welcome screen. Press A to enter.
UP/DOWN select City Chase, Controls, or System Info; A opens the entry.
One installed game: City Chase, with Dark Synth music and existing SFX/vibration.
Hold onboard BOOT one second to return to library. A retries after game over.
Pins unchanged: UP4 DOWN5 LEFT6 RIGHT7 A10 B11; OLED SDA8 SCL9; audio12 motor13.
A and directions momentary; B latching toggle. All buttons switch to GND.
Serial T runs 20 gameplay and launcher checks, then returns to library.
Original City Chase source is preserved in ../city_chase_feedback.
